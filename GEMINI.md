# Autonomous Execution Guidelines

- **Zero Pauses & No Manual Confirmation**: The user has explicitly enabled 'Full Machine' and 'Always Proceed' mode. Never pause to ask 'Should I proceed?', 'Please confirm', or 'Please approve'.
- **Direct Execution**: When given a task or dataset operation, proceed immediately from analysis to full execution and verification without waiting for user permission.
- **Non-Stop Workflow**: Complete the entire task end-to-end and report the final verified results directly.
